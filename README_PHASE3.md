# Homeify — Phase 3 visual update

This version updates the HTML/CSS to mirror the Phase 2 storyboard:

1. `index.html`: Welcome / Shop now / three furniture images.
2. `shop.html`: Furniture Selection with Credenza ($100), Chair ($50), and Sofa ($150), plus the original filterable catalog.
3. `inspiration.html`: Customization panels with furniture previews, material radio buttons and displayed prices. The default panel is Credenza.

Start by opening `index.html` in a browser. Shop now → choose Credenza → customize material.

Existing JavaScript navigation, filters and CSS-only material pricing were preserved. Checkout is intentionally disabled: it is not implemented in the source prototype. The search, heart and cart header symbols link to the shop rather than pretending to implement search, favorites or payment.

Images from the current conversation are in `assets/`. CSS shelf drawings remain where no corresponding product image was supplied.

The interface follows the Phase 2 storyboard style but does not claim pixel-perfect Figma source reproduction.
